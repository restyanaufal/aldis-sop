# Waste Analysis Report

## Tujuan
Mencatat dan menganalisis pemborosan bahan setiap hari — sebagai data untuk memperbaiki forecast pemesanan dan menekan biaya.

## Kapan Digunakan
Setiap akhir hari operasional, oleh Store Leader atau crew yang bertugas tutup.

## Kategori Alasan Waste

| Kode | Alasan | Contoh |
|------|--------|--------|
| **A** | Kadaluarsa / expired | Bahan lewat tanggal |
| **B** | Overproduction | Masak terlalu banyak, tidak terjual |
| **C** | Kerusakan fisik | Roti remuk, patty gosong |
| **D** | Kesalahan proses | Salah rakit, salah order |
| **E** | Bahan tidak layak saat terima | Datang dalam kondisi rusak dari CPNB/supplier |

---

## Ambang Batas Waste Harian

| Kategori | Batas Wajar | Perlu Investigasi |
|----------|-------------|------------------|
| Patty / Sosis | ≤ 5 pcs/hari | > 5 pcs — cek forecast |
| Sayuran | ≤ 300 gram/hari | > 300 gram — cek porsi atau pembelian |
| Produk jadi | 0 pcs | > 2 pcs — cek production planning |

---

## Langkah Analisis Mingguan

Store Leader merekap waste harian setiap **Senin pagi** untuk minggu sebelumnya:

- [ ] Hitung total waste per kategori selama 7 hari
- [ ] Identifikasi alasan terbanyak (A/B/C/D/E)
- [ ] Bandingkan dengan minggu sebelumnya — naik atau turun?
- [ ] Ambil 1 tindakan konkret untuk alasan waste terbesar
- [ ] Laporkan ke Manager / Bisnis Development

---

## Standar Kelulusan
Report terisi lengkap setiap hari tutup — tidak ada hari yang kosong.
