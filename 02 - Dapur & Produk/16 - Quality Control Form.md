# Quality Control Form

## Tujuan
Mendeteksi dan mencatat penyimpangan kualitas produk sebelum sampai ke customer — menjaga konsistensi standar di semua outlet.

## Kapan Digunakan
- Setiap hari: Store Leader atau crew senior melakukan sample check minimal 1 produk per shift
- Saat ada keluhan customer terkait kualitas produk
- Saat ada bahan baru / supplier baru masuk

---

## Form Pengecekan Produk

**Tanggal:** __________ | **Outlet:** __________ | **Pengecekan oleh:** __________

### Produk yang Dicek: __________

| Kriteria | Standar | Hasil | Status |
|----------|---------|-------|--------|
| **Penampilan roti/bun** | Tidak retak, tidak berjamur, tidak lembab | | ✅ / ❌ |
| **Kematangan protein** | Tidak ada bagian pink/mentah, permukaan kecoklatan | | ✅ / ❌ |
| **Kesegaran sayuran** | Tidak layu, tidak berlendir, tidak berbau | | ✅ / ❌ |
| **Porsi sauce** | Tidak berlebihan / tidak terlalu sedikit | | ✅ / ❌ |
| **Tampilan keseluruhan** | Rapi, sayuran terlihat, sauce tidak meleleh keluar | | ✅ / ❌ |
| **Kemasan** | Box tidak penyok, plastik rapat, sachet saos ada | | ✅ / ❌ |
| **Rasa** (jika sample) | Sesuai standar rasa Aldis | | ✅ / ❌ |
| **Waktu saji** | ≤ 5 menit normal, ≤ 8 menit ramai | | ✅ / ❌ |

---

## Kategori Masalah

| Tingkat | Definisi | Contoh | Tindakan |
|---------|----------|--------|----------|
| **Minor** | Tidak memengaruhi rasa/keamanan, hanya visual | Sauce sedikit miring, sayuran kurang rapi | Koreksi, ingatkan crew |
| **Major** | Memengaruhi rasa atau pengalaman customer | Protein terlalu matang/gosong, porsi sauce salah | Retrain crew, perbaiki proses |
| **Critical** | Menyangkut keamanan pangan | Protein tidak matang, bahan kadaluarsa terpakai | Stop produksi, buang batch, lapor ke Manager |

---

## Tindakan Per Tingkat Masalah

### Minor
- [ ] Catat di form ini
- [ ] Koreksi produk sebelum diserahkan ke customer
- [ ] Ingatkan crew secara langsung

### Major
- [ ] Catat di form ini
- [ ] Produk tidak diserahkan — buat ulang
- [ ] Briefing crew mengenai standar yang benar
- [ ] Lapor ke Store Leader

### Critical
- [ ] **Hentikan produksi** dari batch/bahan terkait
- [ ] Buang seluruh produk yang berpotensi terdampak
- [ ] Lapor ke Manager dan tim SCM/CPNB
- [ ] Identifikasi sumber masalah sebelum produksi dilanjutkan
