# Emergency Response — Prosedur Tanggap Darurat Tegalega

> Dokumen terkait: [[SOP-TGL-01 - Opening Outlet]] · [[25 - Penanganan Komplain & Insiden]]

## Tujuan
Memastikan seluruh karyawan tahu apa yang harus dilakukan saat terjadi keadaan darurat — prioritas utama adalah **keselamatan manusia**. Ini krusial di Tegalega karena dapur menggoreng dalam jumlah minyak besar setiap hari — risiko kebakaran minyak lebih tinggi dari dapur non-gorengan.

## Skenario 1 — Kebakaran Minyak (Prioritas Utama)

Karena Tegalega menggoreng dalam wajan besar setiap hari, ini skenario **paling mungkin terjadi** dan paling sering salah ditangani.

### Tanda-tanda Awal
- Minyak terlalu panas hingga berasap tebal
- Api tiba-tiba menyambar dari wajan
- Percikan api dari kompor/tungku ke area sekitar

### ATURAN MUTLAK — Kebakaran Minyak

| ❌ JANGAN | ✅ LAKUKAN |
|-----------|-----------|
| Siram dengan air | Air akan membuat minyak meletup dan memperbesar api drastis |
| Panik dan angkat wajan berlari | Bisa menumpahkan minyak panas ke tubuh/orang lain |
| Tiup api | Justru menyebarkan percikan minyak panas |

### Prosedur yang Benar

```
API MUNCUL DI WAJAN
      │
      ▼
[TERIAK "KEBAKARAN!" — beri tahu semua orang]
      │
      ▼
[Matikan kompor/tungku SEGERA jika bisa dijangkau dengan aman]
      │
      ▼
[Tutup wajan dengan tutup logam / nampan basah — hilangkan oksigen]
      │
      ├─── Api padam ──────────────────────────► Biarkan dingin, jangan dibuka dulu
      │
      └─── Api tidak padam / membesar ─────────► [EVAKUASI SEGERA — jauhi area]
                                                   │
                                                   ▼
                                          [Hubungi 113 & Owner]
```

- Jika ada APAR (Alat Pemadam Api Ringan) tipe untuk minyak/listrik → gunakan, arahkan ke dasar api
- Jangan gunakan APAR tipe air untuk api minyak

---

## Skenario 2 — Luka Bakar / Tersiram Minyak Panas

### Tindakan Segera
1. Jauhkan korban dari sumber panas
2. **Alirkan air mengalir suhu ruang (bukan es) ke area luka bakar selama minimal 10–15 menit**
3. Jangan oles pasta gigi, kecap, atau bahan rumahan lain ke luka bakar
4. Jangan pecahkan lepuhan yang muncul
5. Tutup longgar dengan kain bersih setelah didinginkan
6. Jika luka bakar luas/parah (melepuh besar, area luas) → hubungi 119 segera
7. Kepala Dapur catat insiden dan hubungi Owner

---

## Skenario 3 — Kebocoran Gas (Jika Pakai LPG)

### Tanda-tanda
- Bau gas kuat (bau busuk/telur busuk)
- Suara desis dari selang/regulator
- Api kompor tiba-tiba padam sendiri

### Prosedur DILARANG DAN WAJIB

| JANGAN | LAKUKAN |
|--------|---------|
| ❌ Nyalakan/matikan lampu atau listrik | ✅ Matikan regulator gas di tabung segera |
| ❌ Menyalakan api apapun | ✅ Buka semua pintu/jendela — ventilasi maksimal |
| ❌ Mencoba cari sumber kebocoran sendiri | ✅ Evakuasi semua orang, telepon 113 dari luar |

---

## Skenario 4 — Customer Sakit / Cedera di Lokasi

1. Segera dekati dan tanyakan kondisi dengan tenang
2. Sediakan tempat duduk yang aman
3. Hubungi 119 jika kondisi terlihat serius
4. Kepala Dapur catat insiden dan hubungi Owner

## Latihan Darurat Berkala

- Bulan ganjil: cara menangani kebakaran minyak (tutup wajan, matikan kompor)
- Bulan genap: review prosedur luka bakar & P3K dasar
